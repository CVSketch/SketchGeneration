# 可微渲染器

渲染器：把「笔画参数」画到画布上，变成一张[[栅格图]]。

**可微**见 [[可微]]：参数动一点，画布也光滑地变一点，[[梯度]]能往回走。

普通画图程序（比如 Photoshop 盖一笔）往往不可微。神经网络渲染器是「参数 → 颜色」的可微近似。

[[Learning-to-Paint]] 把这一步叫 $trans$：

$s_{t+1} = trans(s_t, a_t)$

没有它，评论家只能猜环境；有了它，演员能直接收到「笔偏了」的信号。论文把这种算法叫 model-based DDPG。你先记住：环境被显式画出来了，而且能求导。

素描里如果要优化[[贝塞尔曲线]]的控制点，也需要可微地把线画成图。[[DiffSketcher]] 就是这样。
