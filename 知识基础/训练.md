# 训练

训练 = 拿许多带答案的例子，反复改[[模型是什么|模型]]里的[[数字和参数|参数]]，让输出越来越接近答案。

一次训练循环可以想成：

1. 模型先猜。
2. 用[[对错怎么量-损失|损失]]量「猜得有多错」。
3. 用[[梯度]]和[[反向传播]]算出每个参数该往哪边拧。
4. 轻轻拧一下参数。
5. 换下一批例子，再来。

**训练集**是拿来拧参数的。  
**验证集 / 测试集**是不让它看见答案来拧的，只用来考试。混在一起，成绩会假好，叫「偷看考卷」。

训练完，参数就冻住，以后只做[[推理]]。

相关：[[监督]]、[[过拟合]]。
