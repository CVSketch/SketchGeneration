# 状态、动作、奖励

[[强化学习]]的三个零件。用画画说：

| 名字 | 记号（论文里） | 人话 |
|---|---|---|
| 状态 | $s_t$ 或 $(C_t, I, t)$ | 现在画布什么样、目标是谁、第几步 |
| 动作 | $a_t$ | 下一笔的位置、形状、颜色、深浅 |
| 奖励 | $r(s_t,a_t)$ | 这一笔让局面好了多少 |

[[Learning-to-Paint]] 里奖励写成：

$r = L_t - L_{t+1}$

$L$ 是「现在的画」和「目标」差多远。这一笔之后差距变小，$r$ 就是正的。$L$ 他们不用死板的[[像素差-L2]]，而用[[对抗与判别器]]的分数。

转移：做完动作，状态变成下一张画布。如果这一步能求导，就叫 $trans$，见[[可微渲染器]]。
