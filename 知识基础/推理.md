# 推理

推理 = 参数不再改，拿新输入走一遍[[模型是什么|模型]]，得到输出。

也叫测试、生成、跑 demo。

和[[训练]]的差别：

| | 训练 | 推理 |
|---|---|---|
| 改参数吗 | 改 | 不改 |
| 要标准答案吗 | 要，用来算[[对错怎么量-损失\|损失]] | 不要 |
| 慢在哪 | 算对错、算[[梯度]] | 只做一次向前计算 |
| 你看见的「出图」 | 一般不是 | 是 |

[[Learning-to-Paint]] 里：推理是演员看画布出下一笔；训练还要评论家打分、还要[[可微渲染器]]把对错传回去。

相关：[[前馈]]、[[自回归]]。
