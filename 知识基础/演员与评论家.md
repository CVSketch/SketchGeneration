# 演员与评论家

这是[[强化学习]]里一对搭档，不是话剧术语。

**演员**（Actor）：看见[[状态-动作-奖励|状态]]，决定下一[[状态-动作-奖励|动作]]。画画里就是「下一笔怎么画」。

**评论家**（Critic）：看见状态，估计「从这儿往后还能拿多少分」。不直接画画。

为什么要两个人：

- 只靠这一笔的即时奖励，演员会贪眼前。
- 评论家告诉它：这一笔也许眼前分不多，但后面好收工。

评论家估的那个数常写成 $V(s_t)$：

$V(s_t) = r(s_t,a_t) + \gamma V(s_{t+1})$

人话：这一步的分，加上打了[[折扣]]的「下一步还能值多少」。

演员要最大化：这一笔的分，加上「画完这一笔之后，评论家觉得新画布值多少」。新画布由[[可微渲染器]]得到，所以分能传回演员的[[数字和参数|参数]]。

用的时候（[[推理]]）只留演员。评论家是教的时候用的。

出现在：[[Learning-to-Paint]]。
