# 基准与 SOTA

对着 [[任务定义]] 写。过程生成**没有**一张大家公认的「过程 SOTA 表」。现成考卷几乎全是成品草图。要报超过前人的数字，必须先说清：你借哪张成品表，自己又加了哪几把过程尺子。

## 现成考卷（成品）

| 集合 | 什么东西 | 谁在用 | 常见数字 |
| :--- | :--- | :--- | :--- |
| QuickDraw | 约 $5000$ 万简笔，$345$ 类，**自带笔序** | [[StrokeFusion]]、SketchRNN、ChiroDiff | [[StrokeFusion]]：$\ge 8$ 笔 FID **$17.76$**（比 ChiroDiff $27.78$ 低） |
| TU Berlin | $2$ 万张、$250$ 类，非画家 | [[StrokeFusion]] | 该文 FID **$33.68$** |
| FaceX / Creative Birds / Creatures | 更难的人脸和创意生物 | [[StrokeFusion]]、VQ-SGen | FaceX 上该文 FID **$7.27$**（别人约 $99$～$155$） |
| 文生线（自建提示） | 一句话出矢量线 | [[DiffSketcher]]、[[SVGDreamer]]、[[SketchAgent]] | CLIP 分类 / 美感打分，各家提示不同，不能直接横比 |
| SketchRef（2024 预印本） | 对照照片做可识别、结构一致 | 成品合成评测 | 不是顶会基准，可参考「简和能认」要一起报 |

[[StrokeFusion]] 的表是当前**矢量成品**里最硬的一组公开数字。只做过程、不碰无序笔画扩散，很难在这张表上「全面超过」。也不该把那当作主战场。

## 过程侧几乎没有官方榜

| 工作 | 他们怎么评 | 缺什么 |
| :--- | :--- | :--- |
| [[Inverse-Painting]] | 最后一张 [[FID]] / [[LPIPS]]，区域 [[IoU]]，人看像不像在画 | 没有素描版；训练是丙烯风景 |
| [[ProcessPainter]] | 最后一帧 + 人评像不像人 | 主表几乎不管中间顺序 |
| [[SketchAgent]] | CLIP 零样本分类；和人轮流画 | 简笔可识别，不是调子；CVPR 页是 Poster 不是 Oral |
| [[Primitive-Operation-Painter]] | 只有训练损失约 $3.81$ | 没有公开测试集 |

## 若要报「超过前者」

不要幻想 8 周内在 QuickDraw FID 上全面压过 [[StrokeFusion]]。那是组里已经发过的成品题。

更站得住的报法：

1. **借一张成品表当附表**：同一套渲染，报最后一张 FID / CLIP，证明没有把线画崩。目标是「不显著差」，不是刷新 StrokeFusion。
2. **自己立过程表（主表）**，四项都要有数字：
   - 阶段准不准（构图 / 结构 / 排线 / 收细）
   - 这一步改的区域 [[IoU]]
   - 相邻中间稿 [[LPIPS]]（真的往前画了，不是一帧跳完）
   - $20$～$30$ 人：哪段更像课堂示范
3. **必须出现的失败基线**：把 [[Inverse-Painting]] 原权重直接用在线稿上（会按铺色习惯走）；[[SketchAgent]] 画同一对象（简笔）；[[StrokeFusion]] 打乱笔序回放（有线无过程）。

## 训练上怎样才可能把过程数字做上去

- 伪过程要大：[[ProcessPainter]] 用约 $3$ 万段合成序列预训练，真过程只有几十到一百段量级做 [[LoRA]]。8 周抄这个配方，不要从零训视频大模型。
- 监督要对阶段：没有阶段标签，扩散会退化成普通生成。QuickDraw 的笔序能当弱监督，但不能当课堂阶段。
- 表示要适合线：[[距离场]]（[[StrokeFusion]]、[[CoProSketch]]）比直接预测细黑线稳。
- 过程可改：[[Primitive-Operation-Painter]] 的「改前缀再续」比纯栅格自回归容易做中途实验。
- 主损失不要只拿像素差。像素差会逼模型「误差大的地方补一笔」，[[Learning-to-Paint]] 已经证明这不像人。

## 一句冷水

CVPR 不会因为你 FID 低 $0.5$ 就收。过程题要赢，赢在：阶段对、顺序像人、油画那套会失败、成品表没崩。
