# 使用说明

## 打开库

1. 打开 Obsidian
2. 选择「打开文件夹作为库」
3. 选中本目录：`SketchGeneration`
4. 点 [[00-首页]]

笔记按「几乎没学过深度学习、也不靠英文」来写。公式能不用就不用。

## 建议阅读顺序

1. [[00-目录]]：基础知识，一词一页
2. [[入门-读论文前先看]]：一张总览
3. [[任务定义]]、[[10-研究路线]]
4. [[00-本轮目录]]：这轮精读和参考文献
5. 每篇先看笔记的「一句话」，再看要点，要点里的链点进全文译文
6. 要引用或复现时，再对 PDF

## 一篇论文有哪几页

- 笔记：`文献/…/论文名.md`，讲原理和对素描有什么用
- 全文译文：`文献/翻译/论文名-译文.md`，按原文章节写完
- 要点：`文献/翻译/论文名-要点.md`，每条链到译文某一节
- 原文：`附件/pdf/`
- 裁图：`附件/图/论文名/`，只留笔记里用到的

写法见 [[全文翻译约定]]。

## 目录

- `文献/油画过程/`、`文献/素描生成/`、`文献/深大相关/`、`文献/项目/`
- `文献/不读/`：本期明确不读
- `文献/参考文献/`：从精读论文里扒下来的参考文献
- `文献/翻译/`：全文译文和要点
- `文献/翻译/意译/`：第一轮旧意译，只留底
- `研究/`：路线、索引、任务、组会、复现
- `附件/pdf/`、`附件/pdf/参考文献/`
- `模板/`：论文笔记、全文译文、要点、项目、组会发言
