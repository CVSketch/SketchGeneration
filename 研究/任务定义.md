# 任务定义

先看 [[入门-读论文前先看]]。这一页把课题收成一种任务，后面论文和基准都对着它写。

## 一句话

输入一张成品线稿、一句话或半成品，输出**有顺序、有阶段、可中断**的素描过程，而不是只输出最后一张草图。

## 任务类型

计算机视觉里，这不是普通「文生图 / 图生图」。它是：

**过程条件生成**（process-conditional generation），下面可以再拆三条评测：

1. **正过程**：文字或参考图 → 一串中间稿 / 一串笔画
2. **反过程**：成品素描 → 反推它可能怎么画出来
3. **续画 / 中途改**：给到第 $k$ 步，往后接着画，前面尽量不动

表示可以是[[栅格图]]关键帧，也可以是[[矢量图]]笔画，还可以是[[基元操作]]序列。三条路都算过程，不要混成「又做了一张更好看的成品」。

## 和邻近任务的界限

| 邻近任务 | 代表 | 我们不是这个 |
| :--- | :--- | :--- |
| 成品矢量草图 | [[StrokeFusion]]、[[DiffSketcher]] | 他们出最后一组线，不要求课堂阶段 |
| 无训练逐步简笔 | [[SketchAgent]] | 有顺序，但像儿童简笔，不是调子素描 |
| 油画过程扩散 | [[ProcessPainter]]、[[Inverse-Painting]] | 铺色层，不是线、结构、排线 |
| 基元近似作画 | [[Primitive-Operation-Painter]] | 椭圆和旋转矩形铺色块，不是铅笔排线 |

## 第一轮读什么

只读计算机顶会公开全文：CVPR、ICCV、ECCV、NeurIPS、SIGGRAPH / SIGGRAPH Asia、AAAI、ACM MM。有口头或讲解视频的，链到笔记里。

**这轮不读：** [[PDF-Sketch]]（《图学学报》）、[[PaintFlow-交互油画]]、[[PaintFlow-阶段感知]]。预印本 [[CoProSketch]] 只当对照，不精读。

精读清单见 [[00-本轮目录]]。

## 评价不能只报 FID

[[FID]] 只说明最后一张「味道」像不像某一类草图。过程任务至少还要：

- 相邻中间稿的 [[LPIPS]]（这一步有没有真的往前画）
- 改动区域的 [[IoU]]（是不是一次只动一块）
- 阶段分类准不准（构图 / 结构 / 排线 / 收细）
- 人评：像不像课堂示范

现有公开基准大多只管成品。缺口和怎么借现成集合，见 [[基准与SOTA]]。
