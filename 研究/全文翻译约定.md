# 全文翻译约定

库里现在分两层，不要混：

| 文件 | 写什么 |
| :--- | :--- |
| `文献/翻译/论文名-译文.md` | **全文译文**：按原文章节用中文写完 |
| `文献/翻译/论文名-要点.md` | **要点**：每条链到译文某一节 |
| `文献/翻译/意译/` | 第一轮旧意译，只留底，不再改 |

旧模板 `模板/论文译文.md` 是意译稿，新全文用 `模板/论文全文译文.md`。

## 全文译文必须做到

1. 文首 YAML 能解析。`title` 里有英文冒号就加双引号。`source`、`pdf` 写成 `"[[笔记名]]"`。
2. 标题用 Obsidian 语法。公式用 `$...$` / `$$...$$`。内链用 `[[笔记名]]`。图用 `![[图/论文名/文件.png]]`。
3. 按原文的节号写：`## 摘要`、`## 1 引言`、`### 3.2 …`。附录有用的也写。
4. 用自己的中文把每一节写清楚，不要漏方法、实验设置、表、消融、局限。
5. 不要整段粘英文。关键句最多留两三行英文短引，下面写中文。
6. 没在 PDF 里读到的数字不要编。
7. **必须先出图再写译文。** 位图用 `pdfimages` 整张提取；矢量结构图用 `pdftoppm` 按 caption 上方**只裁图本身**。文件名 `fig1.png`、`table1.png`。不要带邻栏文字、页眉、arXiv 戳。不要写「库内暂无裁图」交差。附录效果墙不必全收。
8. 图号、表号跟原文。图出现的那一节写成 `![[图/论文名/fig1.png]]`，下一行用中文写图上是什么。
9. 中文和英文、数字之间加空格。短句。不要翻译腔。
10. 本课题看过程生成。优化步、去噪步、网格图元不要写成作画阶段。图上若是迭代/去噪，caption 里写明。
11. 基础知识点到 `知识基础/` 里已有的词，例如 [[扩散模型]]、[[强化学习]]，不要在译文里重抄定义。

## 要点必须做到

每一条都写成：

```
- 一句话结论。详见 [[论文名-译文#3.2 小节标题]]。
```

读者从要点点进译文，就能对着中文翻原文。

要点必须另有一节 `## 关键图`：写出图上实际看见什么，并链到译文里放这张图的节。没看图不要编。
