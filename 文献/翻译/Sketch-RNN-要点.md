# Sketch-RNN · 要点

## 这篇在干什么

- 本文提出 sketch-rnn：用循环网络生成常见物体的笔画线稿。框架同时覆盖条件生成和无条件生成。详见 [[Sketch-RNN-译文#摘要]]。
- 本文走 [[矢量图]] 生成，不建模像素网格。每条样本是控制笔的运动：往哪走、何时抬笔、何时结束。详见 [[Sketch-RNN-译文#1 引言]]。
- 贡献包括无条件与条件的矢量折线框架，以及针对矢量数据的训练方法。条件模型用来探索 [[潜空间]]。数据和实现都公开。详见 [[Sketch-RNN-译文#1 引言]]。
- 相关工作里，机械臂复刻肖像，或用 [[强化学习]] 找笔刷去逼近照片。这些多是在模仿照片，不是学矢量图的生成模型。详见 [[Sketch-RNN-译文#2 相关工作]]。
- Graves 用手写生成 RNN，再加混合密度网络，给连续点建模铺了路。后续也有人用笔画动作生成矢量汉字。详见 [[Sketch-RNN-译文#2 相关工作]]。
- 模型能补全未画完的草图，也能把已有草图编码进潜空间再条件采样。潜空间插值和向量算术用来改形态，不是改绘画顺序。详见 [[Sketch-RNN-译文#6 结论]]。

## 方法要点

- QuickDraw 里，一条草图是有序点列。每个点是 5 维向量 $(\Delta x, \Delta y, p_1, p_2, p_3)$。偏移相对上一点。$p_1$ 表示落笔连线，$p_2$ 表示抬笔，$p_3$ 表示整幅结束。详见 [[Sketch-RNN-译文#3.1 数据集]]。
- 生成时逐步预测下一个点，也就是偏移加笔的三态之一。这叫按点 [[自回归]]：用上一位置预测下一位置。它是笔画折线序列上最老、最常见的生成[[基线]]。详见 [[Sketch-RNN-译文#3.1 数据集]]。
- 条件模型是序列到序列的变分自编码器。双向 RNN 编码器得到 $h$，再映射出 $\mu$ 和 $\sigma$，按重参数化采样 $z$。同一张输入草图的 $z$ 不是固定值。详见 [[Sketch-RNN-译文#3.2 Sketch-RNN]]。
- 解码器是自回归 RNN。每步把上一点和 $z$ 拼起来，预测下一点的分布。坐标用 $M$ 个分量的高斯混合，笔状态用三分类。训练时喂真值，推理时把刚采到的点滚下去。详见 [[Sketch-RNN-译文#3.2 Sketch-RNN]]。
- 所有序列填充到 $N_{\max}$。真实长度之后写成 $(0, 0, 0, 0, 1)$。采样直到出现结束态，或达到 $N_{\max}$。温度 $\tau$ 只缩放分类 logit 和高斯方差，用来调随机性。详见 [[Sketch-RNN-译文#3.2 Sketch-RNN]]。
- 无条件生成只训练解码器，没有编码器和 $z$。每步输入只有上一点。详见 [[Sketch-RNN-译文#3.3 无条件生成]]。
- 总损失是 $L_R + w_{KL} L_{KL}$。$L_R$ 分偏移似然 $L_s$ 和笔状态交叉熵 $L_p$。$L_s$ 只算到真实长度，$L_p$ 算到填充长度。无条件模型只优化 $L_R$。详见 [[Sketch-RNN-译文#3.4 训练]]。
- 实现上，编码器是 LSTM，解码器是 HyperLSTM。作者把 RNN 单元当抽象组件。超参见附录。详见 [[Sketch-RNN-译文#4 实验]]。
- 在潜向量之间插值再解码，用来看形态怎么过渡。较大的 $w_{KL}$ 通常让中间帧更贴近数据。这是潜空间几何，不是作画阶段。详见 [[Sketch-RNN-译文#4.2 潜空间插值]]。
- 补全未完成草图时，用仅解码器模型。先把不完整前缀编进隐状态，再从该状态继续按点采样。详见 [[Sketch-RNN-译文#4.4 为未完成草图补全结尾]]。
- 训练时还做 KL 退火：先主攻重建，再加大 KL 权重。验证、测试和早停仍用未退火损失。详见 [[Sketch-RNN-译文#2 训练细节]]。

## 数字要点

- QuickDraw：玩家在 20 秒内画指定类别。每个类约 7 万训练样本，另有 2.5k 验证和 2.5k 测试。类数有数百个。详见 [[Sketch-RNN-译文#3.1 数据集]]。
- 先前公开矢量集更小：Sketch 约 2 万条；Sketchy 约 7 万条，并带像素图；ShadowDraw 约 3 万张栅格，外加提取的矢量特征。详见 [[Sketch-RNN-译文#2 相关工作]]。
- 无条件生成图里，$\tau$ 从 0.2 增到 0.9。详见 [[Sketch-RNN-译文#3.3 无条件生成]]。
- 表 1 记录 $w_{KL}=1.00$、$0.50$、$0.25$ 下的 $L_R$、$L_{KL}$，以及仅解码器的 $L_R$。减小 $w_{KL}$ 时 $L_R$ 下降、$L_{KL}$ 上升。条件模型的 $L_R$ 一律低于仅解码器一列。详见 [[Sketch-RNN-译文#4 实验]]。
- cat：$w_{KL}=1.00$ 时 $L_R=-0.98$、$L_{KL}=0.29$；$w_{KL}=0.25$ 时 $L_R=-1.46$、$L_{KL}=1.01$；仅解码器 $L_R=-0.57$。yoga：$w_{KL}=1.00$ 时为 $-0.80$ 和 $0.24$；$w_{KL}=0.25$ 时为 $-1.51$ 和 $1.33$；仅解码器 $L_R=-0.48$。详见 [[Sketch-RNN-译文#4 实验]]。
- Fig. 5 里，cat 模型的 $\tau$ 从左 0.01 增到右 1.0。重建大体同构，偶增删胡须或改尾巴朝向。详见 [[Sketch-RNN-译文#4.1 条件重建]]。
- 补全未完成草图时 $\tau=0.8$。同一前缀可有多条合理结尾。详见 [[Sketch-RNN-译文#4.4 为未完成草图补全结尾]]。
- 附录里，类数从最初 75 类增至数百类。每类仍是 7 万训练、2.5k 验证、2.5k 测试。笔画用 Ramer–Douglas–Peucker 简化，$\epsilon = 2.0$。偏移用单一缩放因子，使训练集标准差为 1。详见 [[Sketch-RNN-译文#1 数据集细节]]。
- $L_{KL}$ 从大于 1 降到约 0.3 时，用标准高斯无条件采样的质量明显提升。再压到接近 0，收益有限。$KL_{\min}$ 常取 0.10–0.50。$\eta_{\min}$ 常为 0 或 0.01。详见 [[Sketch-RNN-译文#2 训练细节]]。
- 编码器隐单元 512，解码器 2048。混合高斯 $M = 20$，潜向量 $N_z = 128$。详见 [[Sketch-RNN-译文#3 模型配置]]。
- 训练：batch 为 100，Adam 学习率 $10^{-4}$，梯度裁剪 1.0，recurrent dropout 保留 90%。$KL_{\min} = 0.20$，$R = 0.99999$。偏移乘独立均匀 $[0.90, 1.10]$。默认 $w_{KL} = 1.00$。详见 [[Sketch-RNN-译文#3 模型配置]]。
- 单类大约能建模 300 点以内。数据侧把点压到 200 点内。75 类同时做无条件生成时，样本多类特征混杂。详见 [[Sketch-RNN-译文#4 模型局限]]。

## 对本课题

- 对照 [[任务定义]]：本课题要有顺序、有阶段、可中断的素描过程。本文只有点列顺序，没有构图、结构、排线、收细那种课堂阶段。详见 [[Sketch-RNN-译文#3.1 数据集]]。
- 解码器每步只预测下一个点。RNN 时间步是自回归滚点，不要写成人类作画阶段。这是笔画序列上的经典点预测基线。[[StrokeFusion]]、[[SketchAgent]] 都从这里出发，再换表示或换生成范式。详见 [[Sketch-RNN-译文#3.2 Sketch-RNN]]。
- 温度 $\tau$ 和潜空间插值说的是采样随机性和嵌入几何。不是过程扩散的去噪步，也不是阶段推进。详见 [[Sketch-RNN-译文#3.2 Sketch-RNN]]。
- 4.4 的补全像「给前缀接着画」。它只是从隐状态继续采点，前面的点也不加阶段标签。不能当成课堂续画基准。详见 [[Sketch-RNN-译文#4.4 为未完成草图补全结尾]]。
- 向量算术改的是头、身等概念属性，例如「整猪减猪头再加到猫脸」。这不是改绘画顺序。详见 [[Sketch-RNN-译文#4.3 素描类比（向量算术）]]。
- 表 1 只报 $L_R$ 和 $L_{KL}$。过程任务还要看阶段对不对、一次改一块、人看像不像示范。详见 [[Sketch-RNN-译文#4 实验]]。
- QuickDraw 是 20 秒内的图标风简笔。类别多、样本多，但不是石膏像素描。只刷这类数据，会和成品简笔题撞车。详见 [[Sketch-RNN-译文#3.1 数据集]]。
- 可借鉴：相对坐标加笔三态的点列表示；前缀续点的补全接口。若动作只定义成「任意位置的下一个点」，模型学不到先大形、后局部。详见 [[Sketch-RNN-译文#3.1 数据集]]。
- 更低的 $L_R$ 不保证视觉上更连贯。高 $w_{KL}$ 更整图连贯，低 $w_{KL}$ 更贴矛盾细节。这是潜空间正则，不是阶段损失。新数据上要先扫 $w_{KL}$。详见 [[Sketch-RNN-译文#6 哪种损失控制「整图连贯」？]]。
- 更长序列难训。复杂类样本偏圆滑，像训练集平均。75 类一起无条件生成会混类。详见 [[Sketch-RNN-译文#4 模型局限]]。
