# ChiroDiff · 要点

对应笔记：[[ChiroDiff]]。全文译文：[[ChiroDiff-译文]]。原文：[[ChiroDiff.pdf]]。对照任务：[[任务定义]]。

> [!tip] 怎么翻原文
> 每个要点都链到全文译文的某一节。点开就能对着中文读，不必再猜在 PDF 哪一页。

## 这篇在干什么

- ChiroDiff 用[[扩散模型]]生成手写、涂鸦一类连续时间折线。加噪和去噪都作用在**整段笔画**上，生成是**非自回归**，不是按点往下预测。详见 [[ChiroDiff-译文#摘要]]。
- 栅格像素写不出「线是怎么画出来的」。多数矢量生成仍是[[自回归]]，只能看过去。本文保留点序，但生成时一次看整段。详见 [[ChiroDiff-译文#1.1 表示与自回归的局限]]。
- SketchRNN 等把连续轨迹压成固定采样率的 token，换分辨率就容易坏。ChiroDiff 看见整段序列，可从数据里隐式学采样率。详见 [[ChiroDiff-译文#1.2 时间分辨率]]。
- 作者选 DDPM，因为多样性和保真度好，训练也稳。现有扩散多在栅格上。本文把它用到变长手绘序列。详见 [[ChiroDiff-译文#1.3 为何选扩散模型]]。
- 无条件、条件、随机矢量化、创意混合、修复都接在同一框架上。自回归擅长的随机补全，这里会弱一些。详见 [[ChiroDiff-译文#1.4 条件生成与应用]]。
- 手绘生成端此前多为因果 Transformer。ChiroDiff 生成端非自回归，同时保留顺序。详见 [[ChiroDiff-译文#2 相关工作]]。

## 方法要点

- DDPM 从各向同性高斯出发，经 $T$ 步反向去噪得到数据。Fig. 3 的「断线」来自笔状态和坐标一起扩散，颜色只标拓扑。这些步是去噪步，不是作画阶段。详见 [[ChiroDiff-译文#3 去噪扩散概率模型（DDPM）]]。
- 表示沿用 SketchRNN 的三点格式：二维坐标加提笔、落笔。真正拿去扩散的是相邻点差分（速度），不是绝对坐标。下标 $t$ 是扩散步，上标 $(j)$ 是序列位置。详见 [[ChiroDiff-译文#4.1 表示：三点格式与速度编码]]。
- 前向过程叫 sequence-diffusion：整条折线上每个（速度，笔状态）同步加噪。各元素独立高斯扰动，共用同一套 $\alpha_t$。详见 [[ChiroDiff-译文#4.2 序列扩散（笔画级前向加噪）]]。
- 二值笔状态当成连续变量一起扩散。生成后再用 $p=0$ 阈值还原成 $\{-1,1\}$。详见 [[ChiroDiff-译文#4.2 序列扩散（笔画级前向加噪）]]。
- 反向每一步都能看见整段带噪序列，因此是非自回归。任意位置都能改，自回归做不到。详见 [[ChiroDiff-译文#4.3 反向过程、损失与非自回归]]。
- 噪声网络是双向 GRU。输入把速度和绝对位置拼在一起。带位置编码的 Transformer 不如 Bi-RNN。详见 [[ChiroDiff-译文#4.3 反向过程、损失与非自回归]]。
- 先验在速度空间是标准正态。积分后对应单位步长离散布朗运动。Fig. 3 是整段折线加噪再整段去噪，不是先画轮廓再填细节。详见 [[ChiroDiff-译文#4.4 从布朗运动到有结构的轨迹]]。
- 生成时可从任意长度 $L$ 的先验启动，$L$ 可以比训练时常见长度更长。Fig. 4 是采样率变高，不是课堂阶段。详见 [[ChiroDiff-译文#4.5 按长度重采样生成]]。
- 条件版用 Bi-GRU 把整段编成 $z$，再拼到每个元素和每个扩散步。解码时还可以提高时间采样率。详见 [[ChiroDiff-译文#重建（条件模型）]]。
- 随机矢量化：点集进 Set Transformer，再条件生成带拓扑的折线。测试集 Chamfer Distance 优于 Das et al.（2021）。详见 [[ChiroDiff-译文#5.4.1 随机矢量化]]。
- 隐式条件不需要编码器：把条件序列加噪到 $T_c<T$，再从那里去噪回来。$T_c$ 越大越像条件。详见 [[ChiroDiff-译文#5.4.2 隐式条件]]。
- 修复把劣质草图当成隐式条件，从 $T_h$ 启动反向。$T_h$ 越大修得越狠，也越容易漂到别的概念。详见 [[ChiroDiff-译文#5.4.3 修复（Healing）]]。
- 创意混合：条件 DDIM 可插值 latent。Quick, Draw! 上改 DDPM 更新，用时间轴一维低通对齐参考，参考样本不必来自训练集。详见 [[ChiroDiff-译文#5.4.4 创意混合]]。
- 可控抽象只改反向方差系数 $k$，不必为不同抽象程度重训。$k$ 接近 0 时少探索，样本更概括。详见 [[ChiroDiff-译文#5.4.5 可控抽象]]。

## 数字要点

- VMNIST 有 1 万样本、10 类数字，划分 80-10-10。Quick, Draw! 本文用 cat、crab、bus、mosquito、fish、yoga、flower。详见 [[ChiroDiff-译文#5.1 数据集]]。
- 扩散步数 $T=1000$。线性 $\beta_{\min}=10^{-4}\cdot 1000/T$，$\beta_{\max}=2\times 10^{-2}\cdot 1000/T$。详见 [[ChiroDiff-译文#5.2 实现细节]]。
- 噪声网络是双向 GRU。VMNIST 2 层、$D=48$；QuickDraw 与 KanjiVG 3 层，$D=128$ / $96$。详见 [[ChiroDiff-译文#5.2 实现细节]]。
- 学习率初值 $\gamma_0=6\times 10^{-3}$，每 epoch 乘 $0.9997$。反向方差取 $\sigma_t^2=0.8\tilde{\beta}_t$。详见 [[ChiroDiff-译文#5.2 实现细节]]。
- 重建看条件 Chamfer Distance，随采样率因子作图。文中没有写出 CD 小数。ChiroDiff 在高采样率下更稳，SketchRNN 在长序列上明显变差。详见 [[ChiroDiff-译文#重建（条件模型）]]。
- 无条件评测用 DDIM、50 步，报成品草图的[[FID]]。特征网在 Quick, Draw! 上自训，不是 ImageNet Inception。详见 [[ChiroDiff-译文#无条件生成]]。
- 本篇正文没有给出 FID 小数。Fig. 5(E) 按柱高估读：VMNIST 约 10 / 11 / 13，KanjiVG 约 15 / 23 / 32，Quick, Draw! 七类平均约 25 / 35 / 40，依次是 ChiroDiff、CoSE、SketchRNN。详见 [[ChiroDiff-译文#无条件生成]]。
- QuickDraw 按笔画数分组的 FID，本篇正文没有。后续 StrokeFusion 表里，少于 4 笔时 ChiroDiff 是 17.17，StrokeFusion 是 19.53。这两个小数来自那张表，不是本篇正文。详见 [[ChiroDiff-译文#无条件生成]]。
- 同一张 StrokeFusion 表上，不少于 8 笔时 StrokeFusion 是 17.76，ChiroDiff 是 27.78。两组都只评成品分布，不评绘画过程。详见 [[ChiroDiff-译文#无条件生成]]。
- Fig. 5(D) 里扩散类收敛更快，SketchODE 明显更慢。文中没有写出具体秒数。详见 [[ChiroDiff-译文#计算效率]]。
- 隐式条件生成后，与条件同类的比例平均约 93%。详见 [[ChiroDiff-译文#5.4.2 隐式条件]]。
- 修复示例取 $T_h=T/5$。详见 [[ChiroDiff-译文#5.4.3 修复（Healing）]]。
- 创意混合的低通卷积窗 $\omega=7$。两序列需等长，条件序列要重采样对齐。详见 [[ChiroDiff-译文#5.4.4 创意混合]]。
- 可控抽象令 $\sigma_t^2=k\cdot\tilde{\beta}_t$，$k\in[0,1]$。详见 [[ChiroDiff-译文#5.4.5 可控抽象]]。

## 对本课题

- 本课题要有顺序、有阶段、可中断的素描过程。这篇输出的是成品矢量折线，属于成品草图生成。详见 [[ChiroDiff-译文#6 结论、局限与未来工作]]。
- 扩散时间步 $t$ 是去噪步。Fig. 3 是整段折线加噪再整段去噪，不能读成构图、结构、排线。详见 [[ChiroDiff-译文#4.4 从布朗运动到有结构的轨迹]]。
- 无条件[[FID]]量的是成品矢量草图分布，不评价笔序或课堂阶段。详见 [[ChiroDiff-译文#无条件生成]]。
- 17.17 和 19.53 来自 StrokeFusion 按笔画数分组的成品 FID，不是本篇自己报的过程分数。少笔画时非自回归整段扩散略优，多笔画时 StrokeFusion 更好。都不能当过程指标。详见 [[ChiroDiff-译文#无条件生成]]。
- 「一次看整段」解决的是自回归看不见全局，不是「先起稿再深入」。需要阶段时，不能把 sequence-diffusion 当成过程模型。详见 [[ChiroDiff-译文#4.3 反向过程、损失与非自回归]]。
- 自回归弱项（随机补全）这篇也弱。续画、中途改要对前面少动，这篇的反向过程却会改任意位置。详见 [[ChiroDiff-译文#1.4 条件生成与应用]]。
- 局限：矢量比栅格更怕噪；速度积分让位置噪声随序列变长而累积。长线、密线不能直接套这套速度扩散。详见 [[ChiroDiff-译文#6 结论、局限与未来工作]]。
